# Jogo da Forca em C

Implementação do jogo da forca em Linguagem C para terminal, utilizando manipuladores nativos da biblioteca `string.h` e renderização em arte ASCII.

# Sobre o Projeto
O sistema realiza sorteios de palavras a partir de matrizes estáticas de caracteres e valida os acertos e erros via busca por ponteiros.

# Funcionalidades
- **5 Categorias Temáticas:** Seleção de temas por menu interativo.
- **Manipulação de Strings:** Uso de ponteiros e funções `strcpy`, `strchr` e `strlen`.
- **Interface Terminal:** Impressão condicional do enforcador em ASCII.

# Tecnologias
- Linguagem C (C99)
- Compilador GCC / Clang

# Como Executar
1. Clone o repositório: `git clone https://github.com/SeuUsuario/jogo-da-forca-c.git`
2. Acesse a pasta: `cd jogo-da-forca-c`
3. Compile o código: `gcc main.c -o forca`
4. Execute: `./forca` (Linux/macOS) ou `forca.exe` (Windows)
